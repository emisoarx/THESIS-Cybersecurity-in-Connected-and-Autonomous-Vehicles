## 🎯 Objetivos da Pesquisa
O foco principal é analisar como veículos modernos (V2X) podem se proteger contra:
1. **Data Injection:** Injeção de dados falsos em sensores.
2. **Sybil Attacks:** Falsificação de múltiplas identidades na rede.
3. **Man-in-the-Middle:** Interceptação de comandos entre a nuvem e o veículo.
